# Security Policy

This site is a Go program that serves the docs of [Tifa](https://github.com/liustack/tifa) and a home page. It keeps no accounts and no user data.

Please report a security issue privately, not in a public issue. Use [GitHub Security Advisories](https://github.com/liustack/tifa-web/security/advisories/new) to open a private report. For a vulnerability in Tifa itself, use [the advisories of the Tifa repository](https://github.com/liustack/tifa/security/advisories/new).
